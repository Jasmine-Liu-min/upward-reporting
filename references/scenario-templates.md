# Scenario Templates

Choose scenario after audience. Then apply the role lens.

## Weekly Or Project Update

```text
本周结论：{整体判断 + 最大变化 + 是否需要管理层动作}

已完成：
- {成果，不写流水账}
- {成果}

下周重点：
- {优先级1 + 交付标准 + 日期}
- {优先级2 + 交付标准 + 日期}

风险与阻塞：
- {问题 + 影响 + 当前方案 + 需要谁帮助}

需要支持或决策：
- {具体请求；如果无请求，写“暂无需额外支持，会在{日期}同步下一次进展。”}
```

## Risk Escalation

```text
结论：{风险}可能导致{影响}，最晚需要在{日期}前处理。我建议{推荐动作}。

背景：
- {必要背景，不超过3条}

影响：
- 范围：{影响谁/什么系统/什么目标}
- 程度：{数字、时间、成本、质量、客户影响}
- 时间：{什么时候会发生或变得不可逆}

已做动作：
- {动作1 + 结果}
- {动作2 + 结果}

可选方案：
- A：{方案}。收益：{收益}。代价：{代价}。
- B：{方案}。收益：{收益}。代价：{代价}。

我的建议：
- {推荐方案}，因为{判断依据}。

需要您支持：
- {协调/拍板/授权/资源}，截止{日期}。
```

## Decision Request

```text
需要您决策：{决策项}。

我的建议：选择{方案}，原因是{最重要的1-2个理由}。

为什么现在要定：
- {时间压力/依赖/成本/窗口期}

选项：
- 方案A：{内容}。优点：{优点}。风险：{风险}。
- 方案B：{内容}。优点：{优点}。风险：{风险}。
- 不行动：{后果}

决策后动作：
- 若选择{方案}，{负责人}将在{日期}前完成{动作}。
```

## Resource Ask

```text
结论：为保证{目标}在{日期}达成，需要增加/调整{资源}。建议{具体配置}。

现状：
- 当前资源：{人/预算/权限/时间}
- 缺口：{缺什么}
- 影响：{不补资源会怎样}

资源用途：
- {资源1}用于{事项}，预计带来{结果}
- {资源2}用于{事项}，预计带来{结果}

替代方案：
- 不加资源：{代价}
- 调整范围：{代价}
- 延期：{代价}

请求：
- 请在{日期}前确认{具体审批/授权/协调动作}。
```

## Executive One-Pager

```text
一句话结论：
{当前判断/推荐动作/业务影响}

当前情况：
- 目标：{原目标}
- 现状：{当前进度/数字/交付物}
- 偏差：{范围、时间、成本、质量、资源的偏差}

关键事实：
- {事实1}
- {事实2}
- {事实3}

主要风险：
- {风险}：概率{高/中/低}，影响{高/中/低}，应对{方案}

选项与建议：
- 方案A：{优点/代价}
- 方案B：{优点/代价}
- 建议：{推荐方案 + 原因}

需要决策：
- {决策项}，最晚{日期}，否则{后果}
```

## Meeting Readout

```text
结论：本次会议已对{事项}形成{共识/分歧/待决策点}，下一步关键是{动作}。

已确认：
- {共识1}
- {共识2}

待解决：
- {分歧/问题 + owner + deadline}

风险：
- {如果不处理会怎样}

需要您：
- {需要对方知情/决策/协调的动作}
```

## Analysis Insight Update

Use for data analyst outputs with a finding. For deeper DA guidance, read `roles/data-analyst.md`.

```text
业务问题：{这次分析支持什么决策/判断}
结论：{最重要发现 + 对业务的含义}
关键依据：
- {指标/分层/对比1}
- {指标/分层/对比2}
可信度：{已验证/方向性判断/仍需补充验证}，限制是{口径/样本/时间窗/埋点/权限}
建议动作：{业务动作/实验/监控/资源调整/停止或继续}
需要支持：{如果需要，写清楚谁在何时做什么}
```

## Analysis Progress

Use when analysis is not ready for a conclusion.

```text
业务问题：{这次分析要回答什么}
当前进展：{已经完成哪些数据准备/口径确认/初步探索}
初步信号：{如果有，写方向性发现；如果没有，说明原因}
当前卡点：{缺数据/口径未定/埋点异常/权限/样本不足}，影响是{会影响什么决策或时间点}
下一步：{何时补齐什么证据，何时给出结论}
需要支持：{请+1或老板协调的具体动作}
```

## Launch Or Delivery Update

Use for product, engineering, or cross-functional delivery.

```text
结论：{上线/交付事项}目前{当前判断}，主要影响是{影响}。我建议{方案}。

关键进展：
- {完成项 + 结果}
- {依赖项 + owner + date}

风险：
- {风险 + 影响 + 应对方案}

取舍：
- {范围/时间/质量/资源之间的取舍}

需要您：
- {确认优先级/范围/延期/资源/协调动作}
```
