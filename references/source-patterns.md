# Source Patterns

Use this only when the user asks why the skill uses these structures or wants alternatives.

- BLUF / bottom line up front: Put the main point at the beginning so busy recipients can decide quickly. Useful for executive emails, risk escalation, and decision memos.
- PPP / Progress, Plans, Problems: A lightweight recurring update format for employee-to-manager, team, executive, board, investor, or advisor reporting.
- Project status reports: Common project-management templates emphasize status, progress, risks/issues, next steps, owners, and asks.
- Executive briefings: Prefer conclusion, business impact, options, recommendation, and decision deadline over chronological detail.

Practical synthesis for Chinese upward reporting:

1. Start with judgment, not background.
2. Translate effort into impact.
3. Pair risk with mitigation.
4. Pair asks with deadline and consequence.
5. Offer options when asking for a decision.
6. Keep tone calm and accountable; avoid flattery, panic, and vague optimism.
7. Avoid color-coded status labels in polished workplace prose unless the user's organization explicitly requires them.
8. Separate direct-manager communication from boss/executive communication: +1 needs working context and operational asks; bosses need impact, recommendation, and decision points.
