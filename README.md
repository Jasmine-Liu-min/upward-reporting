# Upward Reporting · 向上汇报技能

> 把零散的工作笔记、口语吐槽、半成品草稿,一键变成可以直接发给领导的向上汇报:结论先行、带可执行请求、不编数据。

一个 Claude Code skill。你说人话("帮我跟领导汇报一下…"),它产出一版能直接发出去的稿子。

> **从哪看起:** 本文件(README)是项目正门,给人读——想了解这是什么、怎么用,看这里就够。
> 想看完整设计思路(为什么这么设计、架构、扩展),读 [设计说明.md](设计说明.md);想看技能怎么执行,读 [SKILL.md](SKILL.md)(给模型的操作规格);各维度细则在 [references/](references/README.md)。

## 演示:它跑起来什么样

**你给它(随口说):**

> 这周支付改版基本做完了,风控接口还没联调好,可能影响周五上线。帮我发群里给老板

**它给你(IM 形态 + 老板口径,可直接发):**

```text
结论：支付改版主体已完成，当前唯一风险是风控接口未联调，可能影响周五上线。

- 已完成：支付改版主流程开发与自测通过。
- 当前风险：风控接口未联调。周四前联不通，周五上线就得顺延，或先灰度一版不含风控的。
- 下一步：今天对齐联调排期，明天上午给出能否如期上线的明确说法。
- 需要您：暂不需决策；周四若卡住会立即升级，并附两个方案（顺延 / 灰度）。
```

它自动做对了三件事:**判断出受众是老板、渠道是 IM(压成一屏)、把"基本做完了"翻译成了结论 + 风险 + 决策点**——而你只丢了一句话。

更难的场景(数据汇报),它还会守住因果底线:

> 你说:"用了收藏夹的用户留存 75%,没用的 45%,能说收藏夹拉高了留存吧?"
> 它不会顺着说。它会回:这只是**相关**——很可能是活跃用户本来就爱用收藏夹(选择偏差),要确认因果得做 A/B 实验。

## 能力清单

**能做:**

- ✅ **口语 → 成稿**:把吐槽、笔记、草稿翻译成专业汇报,你不用先想"怎么组织语言"。
- ✅ **自动选受众框架**:直属上级(+1)/ 老板高管 / 跨部门 / 外部合作方,各用各的写法。
- ✅ **覆盖常见场景**:周报、风险升级、决策请求、资源申请、一页纸、会议纪要、上线/交付、数据洞察、分析进展。
- ✅ **按职业口径写**:数据分析师、产品经理;角色不明确时先用通用管理层口径,其他角色可扩展。
- ✅ **适配渠道**:微信/Slack(一屏)、邮件(带主题分段)、口头(30 秒)、一页纸(高管版)。
- ✅ **守数据底线**:相关不当因果,没显著不当有效,缺的数据标「待确认」。

**不会做(刻意的边界):**

- ❌ 不替你编没有的数字、日期、负责人。
- ❌ "领导"层级不明时不擅自起草,会先问一句"+1 还是大老板?"。
- ❌ 不堆字数;IM 场景主动压短。
- ❌ 不下超出证据的结论。

## 它怎么工作

一句话:**把汇报者视角("我做了什么")翻译成领导视角("要不要我做决定")。**

收到原始素材后,沿四个维度路由,再成稿:

```
口语/笔记
  │
  ├─ 受众?   +1 / 老板 / 跨部门 / 外部      ← 只说"领导"且不明 → 先反问,不猜
  ├─ 场景?   周报 / 风险 / 决策 / 资源 / 实验读出 …
  ├─ 角色?   数据分析师 / 产品经理 …
  ├─ 渠道?   IM / 邮件 / 口头 / 一页纸          ← 决定形态和长度
  │
  └─ 成稿:结论先行(BLUF) → 最小背景 → 最小证据 → 风险/取舍 → 可执行请求
            └ 全程不编事实,缺的标「待确认」;引用数据时相关≠因果、没显著不下结论
```

四个维度**正交**——"发群里给老板汇报实验" = 老板框架 × 实验场景 × 数据口径 × IM 形态。拆开组合,少量规则就能覆盖绝大多数情况。

## 设计原则(每条都对应领导视角的一个诉求)

1. **受众优先,层级不明先问** —— 给 +1 和给老板的框架不同,选错框架后面全错,所以卡在最前。
2. **结论先行(BLUF)** —— 领导时间稀缺,第一句就得知道要点和要不要做事。
3. **把活动换成影响** —— "开了几个会"是你的成本,"解锁了合同"才是他要的产出。
4. **请求可执行** —— 谁、做什么、什么时候之前、不做的后果;模糊请求会被无限期搁置。
5. **结论强度 = 证据强度** —— 数据岗底线:相关不说成因果,没显著不说成有效。下了超出证据的结论,领导会据此做错决策。宁可结论弱一点,不能逻辑漏一点。
6. **不编事实 + 真人语气** —— 编的数字会误导决策;对仗腔和红黄绿灯标签一眼假。可信先得真实。
